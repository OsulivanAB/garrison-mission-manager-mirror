---

## About Garrison Mission Manager

Garrison Mission Manager (GMM) is a World of Warcraft addon that helps you select the best follower team for mission tables across all expansions (WoD Garrison/Shipyard, Legion Class Hall, BfA, Shadowlands, and more).

- **CurseForge:** https://www.curseforge.com/wow/addons/garrison-mission-manager
- **WoWInterface:** http://www.wowinterface.com/downloads/info23375-GarrisonMissionManager.html
- **Original GitHub:** https://github.com/rowaasr13/garrison-mission-manager
